# Обучение модели с использованием XGBoost

Курсовой проект по машинному обучению. Обучение и тестирование модели на наборе данных, визуализация результатов.

## Технологии
- Python
- Jupyter Notebook
- XGBoost, Pandas, Matplotlib

## Возможности
- Подготовка данных
- Обучение модели с использованием XGBoost
- Оценка точности и метрик
- Визуализация результатов
