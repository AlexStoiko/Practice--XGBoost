# Обучение модели с использованием XGBoost

Разработал классификатор для предсказания результатов кластеризации данных.

## Технологии
- Python
- XGBoost, scikit-learn, Matplotlib

## Реализация
- Подготовил и очистил наборы данных из CSV и текстовых файлов, удалил аномальные значения, объединил источники в единый датафрейм.
- Реализовал предобработку: удаление неинформативных признаков (например, даты), нормализация и разбиение на обучающую, тестовую и валидационную выборки с использованием scikit-learn.
- Обучил модель на основе библиотеки XGBoost, применил настройку гиперпараметров (Grid Search) для повышения точности.
- Оценил качество модели по метрикам accuracy, precision, recall, F1-score, построил графики важности признаков и зависимости результатов с помощью matplotlib.
- Реализовал сохранение и загрузку модели для повторного использования.
